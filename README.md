# data-glyph.com

Static marketing site for Dataglyph Consulting (data integration services).
Plain HTML/CSS, no build step. Hosted on GitHub Pages with the custom domain in `CNAME`.

## Local preview

    python -m http.server 8000

Then open http://localhost:8000.

## Deploy

Push to `main`. GitHub Pages (Settings -> Pages -> Deploy from branch -> main / root) publishes automatically.
